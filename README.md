# 🏙️ AI Smart City Complaint Management & Predictive Analytics Platform

## 📌 Overview

The AI Smart City Complaint Management & Predictive Analytics Platform is a full-stack web application designed to help manage, analyze, and prioritize citizen complaints using Artificial Intelligence and predictive analytics.

The system provides a secure dashboard where administrators can manage complaints, analyze complaint trends, classify complaints using AI, and identify potential high-risk complaints.

## 🚀 Features

- 🔐 JWT-based user authentication
- 📝 Create, update, view, and delete complaints
- 🤖 AI-based complaint classification
- 📊 Complaint priority analysis
- ⚠️ Predictive risk assessment
- 📈 Interactive analytics dashboard
- 🔎 Search and filter complaints
- 📍 Location-based complaint analytics
- 📷 Complaint image upload
- 📥 CSV export
- 🔔 Complaint submission notifications
- 📊 Category, status, and priority charts
